# 🕵️ Scam Battle

A fast-built prototype for a "Service Learning" project on financial literacy (grades 7–11).

Players chat with 7 characters (6 scammers, 1 friend) to practice spotting fraud and protecting money.

**Tech:** Vanilla JS, Bootstrap, GitHub Pages.
**Note:** This is a rapid prototype. Some bugs and narrative inconsistencies are expected. No progress saving.
